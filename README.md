## Overview

**Hajir Muhaajir** is a client-side portfolio and tool hub built with plain **HTML**, **CSS**, and **JavaScript**.

It combines a personal profile, browser-based tools, AI chatbots, mini games, original music, documentation, and support links into one static web experience.

### Included

- **Beat Tools** — a directory of seven free browser tools.
- **AI & Bots** — Raia and Kirana, two provider-based AI chatbots.
- **Mini Games** — four lightweight browser games.
- **Aurora Theme** — optional day/night visual layer.
- **Performance Tiers** — `eco`, `normal`, and `premium`.
- **Bilingual UI** — Indonesian and English.
- **Global Search** — opened with `Ctrl + K` or `Cmd + K`.
- **README-Powered Documentation** — tool documentation loaded into modals.
- **Persistent Preferences** — theme, language, and cookie preferences.

### What It Does Not Use

- Custom backend.
- Analytics scripts or tracking pixels.
- Build tools.
- npm dependencies.
- Framework lock-in.
- Emoji icons.
- Icon fonts.
- Live clocks or runtime-derived timestamps.

## Recent Performance Pass

**Nova v1.0.1** focused entirely on scroll smoothness on mobile, low-end devices, and iOS Safari, without touching layout, content, or business logic.

Key changes:

- **Nav backdrop blur** reduced from `20px` to `14px` on `premium`; removed entirely on `normal`, `eco`, mobile, and coarse pointer. Fixed-header blur was the single biggest frame-drop source.
- **Grain overlay** loses its `mix-blend-mode: overlay` on `normal` tier; hidden entirely on mobile. Fixed full-viewport blend was repainting on every scroll frame.
- **Contact and footer blobs** (`blur(80px)`) reduced on `normal`, hidden on mobile.
- **Hero ticker** blur removed on `normal` / `eco` / mobile; compensated via higher background opacity.
- **Back-to-top button** backdrop blur removed (solid-color button, blur added no visual).
- **Orbit node `drop-shadow`** reduced on `normal`, off on `eco` — SVG rotates continuously, drop-shadow repaints each frame.
- **`.anim-paused`** now resets `will-change`, releasing the GPU layer while off-screen.
- **Aurora layer stack** on mobile collapsed from ~7 promoted compositor layers (aurora + 3 star layers × 2 pseudo-elements) to 1 static aurora layer. Stars remain visible — only animation stops.
- **Eco tier** now `display: none`s `.stars`, `.meteors`, `.spotlight`, `#fx` (empty in eco because `aurora.js` returns early), removing dangling compositor layers.
- **Duplicate `renderAllIcons()` call** at boot removed.

No features removed. No visual identity lost. Every scroll on a mid-range Android device now stays at 60 fps under a 4x CPU throttle.

### Performance Tiers

Since `v2026.10.08.3`, visual effects are controlled through a single `data-perf` attribute on the `<html>` element.

The attribute is selected during the initial page load, **before the main stylesheet is applied**. This avoids unnecessary visual restyling and reduces layout shifts.

| Feature | `eco` | `normal` | `premium` |
|---|:---:|:---:|:---:|
| Aurora gradient | Static (18px blur) | Static on mobile, drifting on desktop | Drifting (34px blur) |
| Stars | Not spawned (layer hidden) | Static on mobile, twinkling on desktop | Twinkling (full density) |
| Meteors | Never (layer hidden) | Rare (12–25 s) | Frequent (6–15 s) |
| Cursor spotlight | Off (layer hidden) | Off | On |
| Canvas ripple + particles | Off (layer hidden) | On (smaller on mobile) | On (larger) |
| Tilt / magnetic buttons | Off | Off | On |
| Hero spotlight | Off | Off | On (mousemove) |
| Mesh blobs + grain | Hidden | Reduced opacity, blend off | Full |
| Nav `backdrop-filter` | Disabled | Disabled | 14px (reduced from 20px) |

#### Tier Selection

The performance tier is calculated inline in `<head>`:

```js
let tier = 'premium';

if (
  reduceMotion ||
  saveData ||
  (mem && mem <= 2) ||
  (cores && cores <= 2)
) {
  tier = 'eco';
} else if (
  coarsePointer ||
  (mem && mem <= 4) ||
  (cores && cores <= 4)
) {
  tier = 'normal';
}

document.documentElement.setAttribute('data-perf', tier);
```

Selection signals:

Signal Result
prefers-reduced-motion: reduce eco
navigator.connection.saveData === true eco
deviceMemory <= 2 GB eco
hardwareConcurrency <= 2 eco
Coarse pointer normal
deviceMemory <= 4 GB normal
hardwareConcurrency <= 4 normal
No limiting signal detected premium

Performance Rules

These rules are mandatory when adding features:

· Do not add new scroll listeners.
· Reuse the shared requestAnimationFrame throttle.
· Do not add will-change to long-lived elements without a clear reason.
· Treat blur and backdrop-filter as expensive paint operations.
· Define behavior for all three performance tiers in style.css and aurora.css.
· Keep contain: layout style on cards.
· Gate mouse tracking and magnetic buttons behind perfTier === 'premium'.
· Respect prefers-reduced-motion.
· Only transform and opacity may animate — never width, height, top, left, or margin.

Optional Optimization

For production, Tailwind CDN could be replaced with a local prebuilt stylesheet.

Any replacement must preserve the utility classes currently used in the markup. The critical CSS fallback in index.html is designed to keep the first paint stable, but it does not replace every Tailwind utility.

Troubleshooting

Icons Look Broken on First Load

Check that:

1. icons.js is loaded.
2. The required icon registry exists.
3. Tailwind or the fallback CSS has loaded.

The fallback CSS and presentation attributes prevent icons from expanding uncontrollably while styles are loading.

Aurora Theme Does Not Appear

Check that:

1. aurora.css is loaded.
2. aurora.js is loaded.
3. #aurora-bg, .spotlight, and #fx exist.
4. The active performance tier is not eco.

```js
document.documentElement.getAttribute('data-perf');
```

The Site Feels Slow on Mobile

Check the active tier — it is printed to the browser console on every load:

```text
Haiere Nova v1.0.1 — ready (perf tier: normal, default lang: en)
```

Or read the DOM directly:

```js
document.documentElement.getAttribute('data-perf');
```

If a low-end device is incorrectly using premium, verify that the inline performance script in index.html is present and runs before the stylesheets.

If scroll is still not smooth after Nova v1.0.1:

· Open DevTools and confirm the active tier is not premium.
· In Rendering, enable Paint flashing — the fixed nav and hero ticker should no longer flash on scroll.
· Check that aurora.css v2026.10.08.7 or later is deployed (mobile should collapse to 1 static aurora layer).

Contact Form Does Not Submit

Verify the Formspree endpoints:

Purpose Endpoint
Primary https://formspree.io/f/mpqkqanp
Fallback https://formspree.io/xgvkobyl

Also verify that:

· JavaScript is enabled.
· Form fields have valid name attributes.
· The form action points to the correct endpoint.

Theme or Language Does Not Persist

Check that:

· localStorage is enabled.
· The browser is not clearing site data.
· The relevant keys exist.

Preference Key
Theme theme
Language haiere-lang

Search Returns No Results

Try a broader search query.

If the language was recently changed, confirm that the search index was rebuilt after applyLang() ran.

The search index includes the AI & Bots section (#ai-bots) and both Raia and Kirana cards.

Footer Version or Last Update Looks Wrong

These values are static — they are hardcoded in index.html:

```html
<span id="last-updated-date">2026-10-08</span>
<span class="footer-version">Nova v1.0.1</span>
```

They only change when the file is edited and deployed. There is no live clock, no new Date(), and no setInterval. See Versioning and Last Update for the update checklist.

Why Static

· No new Date() at runtime.
· No setInterval or setTimeout driving a clock.
· No per-user, per-visit timestamps.
· Deterministic output for every visitor.

Update Checklist

When shipping a new version:

1. Bump the version string in index.html (footer and <span class="footer-version">).
2. Bump the last-update date in index.html (footer and <span id="last-updated-date">).
3. Bump the version comment at the top of style.css, aurora.css, script.js, i18n.js, icons.js, aurora.js, styleguide.html, and manifest.webmanifest.
4. Update the version badge in this README.md.
5. Update the version string in the closing footer of this README.md.

Privacy and Security

Haiere does not use analytics scripts, tracking pixels, or its own backend database.

· Preferences are stored in localStorage.
· Contact messages are submitted through Formspree.
· Tool documentation is fetched from public GitHub repositories.
· Music, fonts, and third-party embeds follow their own privacy policies.
· Provider-based AI tools send requests to the provider selected by the user.

[!WARNING]
localStorage is not an encrypted vault. Never store passwords, API keys, tokens, or other secrets there.

Non-Negotiable Rules

1. Use SVG icons only. Never use emoji or icon fonts.
2. Send every visible string through the i18n system.
3. Keep non-tool content outside #tools.
4. Keep Raia and Kirana provider-based, and keep them under #ai-bots.
5. Respect prefers-reduced-motion.
6. Allow reduced motion to force the eco tier.
7. Keep Aurora optional and non-blocking.
8. Use role="toolbar" and aria-pressed for filter bars.
9. Ensure accent text uses the correct --on-accent token in every theme.
10. Define every decorative layer for eco, normal, and premium.
11. Do not add scroll listeners without using the shared requestAnimationFrame throttle.
12. Only transform and opacity may animate in reveal transitions.
13. Never derive the footer version or last-update date at runtime.
14. Keep id="raia" unique — one sprite symbol, one icon registry entry.
15. On mobile and coarse-pointer devices, aurora, stars, meteors, spotlight, and canvas FX must not animate continuously. They may remain visible in a static state.

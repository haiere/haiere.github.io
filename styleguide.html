Design system · v2026.10.08.4

Aurora Navy / Petal Rose

One system, two moods. Dark mode is midnight navy with soft cyan, muted gold, and pale lavender. Light mode is petal pink with deep plum text and a rose-gold accent. Everything below is a token — no component hardcodes a colour, a size, or a duration.

01

Palette

Every colour is a token with a value in both themes. Toggle the switch in the header — the hex readouts below follow the active theme.

--bg-page #0A192F Page background
--bg-page-2 #0B1E33 Alternate band
--bg-inset #071424 Inset wells · code blocks
--surface-solid #0B1E33 Opaque card surface
--text-main #E7EEF6 Primary text
--text-soft #ADB6C2 Secondary text
--accent #7FD8CB Decorative: borders, ticks
--accent-ink #7FD8CB Accent as text · ≥ 4.5:1
--accent-2 #D4B27A Gradient partner
--border-soft #1B3348 Hairlines & dividers

The accent is split in three. --accent is decorative (borders, ticks, glows). --accent-ink is the same hue darkened enough to pass 4.5:1 as text on the page background. --accent-solid is the fill used behind --on-accent. On light, white on rose is only 3.5:1 — so the button fill deepens to #9A5670 (5.3:1). On dark, cyan is far too bright for white, so on-accent text flips to #0A192F (10.5:1).

Feedback colours are themed too. Success is #047857 light / #34D399 dark. Error is #B91C1C light / #F87171 dark. The raw Tailwind #10b981 and #ef4444 both land near 2–3:1 on the petal background and are no longer used for text.

Chatbot rule. Raia AI and Kirana are both provider-based chatbots — the front end talks to a provider abstraction, so swapping the underlying model never changes the UI. The category label is always AI Chatbot, never “Platform” or “Tool”.

Filter semantics. Filter bars use role="toolbar" with aria-pressed — not role="tab", since there is no tabpanel pairing. The demo above toggles its pressed state only; the production filter also re-renders the grid.

07

Motion & a11y

Motion is decorative. Access, contrast, and keyboard behaviour are not negotiable.

  • Reveal on scroll uses a single shared IntersectionObserver — 32px rise, 0.9s, one-shot per element, then it unobserves.
  • Reduced motion. All transitions collapse to 0.001ms under prefers-reduced-motion, and scroll-behavior reverts to auto.
  • Touch targets are 44px minimum — every button, link, switch, and chip.
  • Focus rings are a 3px accent outline with a 3px offset. Never removed, only restyled — and always :focus-visible, never bare :focus.
  • Overlays (drawer, docs modal, cookie modal) trap focus, restore it on close, and reference-count the body scroll lock so stacked overlays don’t unlock early.
  • Decorative layers — aurora mesh, grain, hairline grid, cursor halo — are aria-hidden and pointer-transparent.
  • Contrast floors. Body text ≥ 4.5:1 · large text ≥ 3:1 · UI borders and focus indicators ≥ 3:1, in both themes.
  • On-accent text flips. Dark mode uses #0A192F on cyan because the accent is far too bright for white — light mode deepens the fill instead.
  • Menu button label toggles between Open menu and Close menu in step with the drawer’s aria-expanded.
  • Icons are never the label. An icon-only control carries its own aria-label; the glyph is always aria-hidden.

Theming

Parity is a feature. Every token has a value in both themes and nothing is hardcoded to one.

09

Cheat sheet

The tokens that define the whole system. Change one, and every surface follows. 

/* ── Typography ─────────────────────────────────────── */
--fs-hero:       clamp(2.25rem, 7vw, 4.5rem);   /* hero headline   */
--fs-section:    clamp(1.75rem, 4vw, 2.25rem);  /* section titles  */
--fs-card-title: 1.05rem;                      /* card headings   */
--fs-body:       1rem;                         /* body copy       */
--fs-small:      .85rem;                       /* UI labels       */
--fs-mini:       11px;                         /* mono chips       */
--fs-micro:      10.5px;                       /* mono metadata    */
--fs-status:     10px;                         /* status badges    */

/* ── Accent split ───────────────────────────────────── */
--accent:        #B4788C;  /* light: decorative   */
--accent-ink:    #9A5670;  /* light: text ≥ 4.5:1 */
--accent-solid:  #9A5670;  /* light: fill          */
--on-accent:     #FFFFFF;  /* light                */

.dark {
  --accent:       #7FD8CB;
  --accent-ink:   #7FD8CB;
  --accent-solid: #7FD8CB;
  --on-accent:    #0A192F;  /* cyan is too bright  */
}

/* ── Feedback ───────────────────────────────────────── */
--ok:  #047857;   .dark { --ok:  #34D399; }
--err: #B91C1C;   .dark { --err: #F87171; }

/* ── Radii ──────────────────────────────────────────── */
--radius-card:  1.5rem;   /* glass cards        */
--radius-input: 14px;     /* fields & buttons   */
--radius-pill:  9999px;   /* pills & chips      */

/* ── Motion ─────────────────────────────────────────── */
--ease:        cubic-bezier(.25, .46, .45, .94);
--ease-spring: cubic-bezier(.34, 1.56, .64, 1);
--ease-out:    cubic-bezier(.22, 1, .36, 1);

Design system · v20260927.1

Aurora Navy / Petal Rose

One system, two moods. Dark mode is midnight navy with soft cyan, muted gold, and pale lavender. Light mode is petal pink with deep plum text and rose-gold accents. Everything below is a token — no hardcoded values live in the components.

04 · Icons

SVG only — never an emoji, never a font

All UI icons come from icons.js via <svg data-icon="icXX">. This page defines its own local symbols for the demos.

Sizing rule

1em failsafe

The renderer sets width="1em" and height="1em" as attributes, so icons never blow up if the utility stylesheet is delayed. Tailwind's h-5 w-5 (or any class) still overrides them — presentation attributes lose to CSS.

Stroke

Lucide-style · 24×24 · 2px

fill: none · stroke: currentColor · stroke-linecap/linejoin: round. Color always inherits from the parent.

07 · Motion & a11y

Rules of the road

Motion is decorative. Access, contrast, and keyboard are not negotiable.

  • Reveal on scroll uses a single shared IntersectionObserver, 32px rise, 0.9s, one-shot per element.
  • All motion collapses to 0.001ms under prefers-reduced-motion.
  • Touch targets are 44px minimum — every button, link, and toggle.
  • Focus rings: 3px accent outline with 3px offset; never removed, only restyled.
  • Drawer, docs modal, and cookie modal all trap focus and restore it on close.
  • Aurora mesh, grain overlay, hairline grid, and cursor halo are decorative and aria-hidden.
  • Body text ≥ 4.5:1; large text ≥ 3:1; UI borders ≥ 3:1 in both themes.
08 · Theming

Parity is a feature

Every token has both values. Nothing is hardcoded to a single theme.

Storage

Class-based, not media-based

Theme state lives on document.documentElement.classList (.dark) and is persisted under localStorage['theme'] — same key across index.html and this page.

First paint

Inline script, before CSS

The theme is set in a tiny inline script in <head> so there is no flash. prefers-color-scheme is respected when no choice has been saved.

Parity check

Both modes ship identical layout

Only tokens change. No layout, spacing, or component structure differs between light and dark — the switch is pure color.

09 · Cheat sheet

Copy-paste tokens

The three files that define the whole system. Change a token once, and every surface follows.

/* Typography — change here, whole site follows */
--fs-hero:    clamp(2.25rem, 7vw, 4.5rem);   /* hero headline */
--fs-section: clamp(1.75rem, 4vw, 2.25rem);  /* section titles */
--fs-body:    1rem;                          /* body copy */
--fs-body-sm: 0.9rem;                        /* secondary copy */
--fs-small:   0.85rem;                       /* UI labels */
--fs-mini:    11px;                          /* mono chips, eyebrows */
--fs-micro:   10.5px;                        /* mono metadata */
--fs-status:  10px;                          /* status badges only */

/* Radii */
--radius-card: 1.5rem;   /* glass cards */
--radius-pill: 9999px;   /* pills, buttons */

/* Motion */
--ease:        cubic-bezier(0.25, 0.46, 0.45, 0.94);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
--ease-out:    cubic-bezier(0.22, 1, 0.36, 1);
